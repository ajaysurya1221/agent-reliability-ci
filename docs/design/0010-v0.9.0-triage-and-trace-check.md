# 0010: v0.9.0 packaging re-freeze

The operator approved the two-day triage/release plan on 2026-11-05. This record
authorizes only its packaging re-freeze, following `docs/RELEASING.md`.

## Why this version

v0.9.0 distributes the already-merged read-only cross-run `trace-check` command
and adds `arci triage` for representative paired failures and containing-event
context. Both read existing native stores. Statistical decisions, sample sizes,
stopping rules, schemas, runner behavior and replay semantics are unchanged.

The new triage command returns the re-derived gate's exit code unless diagnosis
is invalid, in which case it returns 3. Trace drift never changes the statistical
verdict. Context identifies a recorded position, not a root cause or the quality
of a model. Group selection is descriptive and leaves every trial in its gate.

## Delivery gate

The version-bearing PR must pass independent review, the full local checks and
exact-revision hosted CI. Its merge commit must pass CI before the annotated
v0.9.0 tag is pushed. The tag triggers the existing workflow: build once, test
the built wheel on Ubuntu/macOS with Python 3.11/3.14, publish the same wheel and
sdist through OIDC with attestations. Downloaded PyPI bytes must match the workflow
checksums and pass the installed workflow before delivery is reported complete.

Old tags, artifacts, archived stores and execution receipts are preserved.
No dependency additions, semantic frozen amendments or human adoption claims are
authorized by this record. No prior release is rebuilt or replaced.
