# 0013: v2.0.0, suites and the LangChain adapter

Release record by the orchestrator (Claude Fable 5.2), 2026-11-11. Implementation by Codex
Astra 6 from briefs under `plan/exec/v2/tasks/`; every task was reviewed by independent
agents with a skeptic per finding, and fix rounds were verified before merge. Decisions are
in `plan/exec/v2/DECISIONS.md` (D-01 to D-10).

## Why 2.0.0

Two additions change what ARCI is for: a gate over many tasks (ADR 0011) and an adapter for
agents built with LangChain's `create_agent` (ADR 0012). Nothing in v1 is removed or
changed: every `arci/0.5` record, command and test behaves as in v1.0.0, and the 54 files
frozen at v1.0.0 that this release did not need to touch still carry their v1.0.0 hashes.
The major version marks the new experiment kind and the new optional dependency, not a
break.

## What ships

- **Suite experiments** (`arci-suite/1`): `SuiteManifest`, balanced rounds, two one-sided
  betting tests with a proved bound of alpha/2 on each directional error under the
  assumptions in `docs/STATISTICS_SUITE.md`, a pure suite gate, a calibration bench, a
  runner that schedules pairs, a store, and suite support in `run`, `gate`, `report`
  (Markdown, JSON, HTML), `triage`, `diff` and `plan`.
- **Fault accounting** in every report: how often each declared fault fired, per arm.
- **LangChain adapter** (`arci.adapters.langchain`, extra `agent-reliability-ci[langchain]`),
  a quickstart example, a recipe and `arci init --langchain`.
- **Single-file HTML report** and an optional pull-request comment from the Action.
- **One pre-registered study** on two local models (`plan/exec/v2/study/`): BLOCK at round
  1, against the orchestrator's written expectation of PASS.

## Frozen changes in this release

- `pyproject.toml`: version 2.0.0 (the extra, the `adapters` group and the type-check
  exclusions were added at integration, ADR 0012). `uv.lock`: regenerated; the record of
  what moved is in the commit message.
- `src/arci/__init__.py`: `__version__ = "2.0.0"`.
- `FROZEN.sha256`: entries for this record and the two files above.
- The README first screen contracted by ADR 0009 is unchanged. A section for suites and
  LangChain follows it.

## What is not in 2.0.0

`minimize`, `bundle`, `replay` and `trace-check` for suite stores; async LangChain agents,
interrupts and tools with injected arguments; MCP clients other than ARCI's own revision;
command-agent suites beyond what the schema already allows (untested end to end); JUnit for
suites. Each refuses with one line.

## What the release may and must not say

As in `docs/STATISTICS_SUITE.md` and ADR 0011. In particular: no claim of fewer runs than
any other method, no verdict from one run, no per-task conclusions from a suite PASS, and
nothing about tasks outside the registered suite. The study is one comparison on one suite.
