## Goal
Measure the packaged demo on clean reference machines (GitHub-hosted runners), the way the memo's target is phrased ("p50 ≤ 2 min; p95 ≤ 3 min on clean reference machines"), with no secrets and no telemetry. These are machine timings, not receipts (protocol §1.4).

## Changes
1. `.github/workflows/ttfv-reference.yml`: `on: push: branches: ['sprint/**']` and `workflow_dispatch`; `permissions: contents: read`; matrix `ubuntu-latest`, `macos-latest`; Python 3.12 via the same pinned `actions/setup-python` SHA used in ci.yml; install uv with the same pinned action/version as ci.yml; then a bash step that, in `$(mktemp -d)`, runs `uvx --from agent-reliability-ci==0.8.0 arci demo` five times: sample 1 with `UV_CACHE_DIR=$(mktemp -d)` (cold), samples 2–5 warm; each sample piped through a timestamping filter (`date -u +%Y-%m-%dT%H:%M:%SZ` per line) into `sample-<n>.log`, with the exit code captured under `bash` (`${PIPESTATUS[0]}`); a small Python (stdlib) step parses the logs into `reference-<os>.json`: per sample `command_start`, `demo_banner` (first line containing `arci demo:`), `demo_verdict` (first `VERDICT:`), `all_steps_held`, `exit_code`, plus `runner` (`${{ runner.os }}`, `${{ runner.arch }}`), `python`, `uv --version`, `package: agent-reliability-ci==0.8.0`; `actions/upload-artifact` (same pinned SHA as ci.yml) uploads the JSON and logs as `ttfv-reference-<os>`. Time limit 25 min per job. All actions SHA-pinned with version comments, as in ci.yml.
2. `plan/exec/scripts/reference_stats.py` (stdlib only, ruff-clean): reads one or more `reference-*.json` files, prints per OS the five `total` values (command_start → all_steps_held), p50 and p95 (nearest-rank), and whether each is within the memo target (120 s / 180 s); exits 0 always (it reports, it does not gate).
3. `docs/measurement/reference-machines/README.md`: what a reference machine is (a clean GitHub-hosted runner, no cache, no checkout), how the JSON is produced (the workflow), that these are not receipts and never count as cold readers, and how to read p50/p95.
   The JSON files themselves are committed by the orchestrator after downloading the artifact.
