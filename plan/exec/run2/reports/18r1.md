- .github/workflows/ttfv-reference.yml: the timing step is now `shell: python` (stdlib only). It takes 5 cold samples, each with its own new `UV_CACHE_DIR` (mkdtemp, checked empty, `uv_cache_entries_at_start` recorded), then 2 warm samples that reuse the cache the 5th cold sample filled. Each sample runs in its own process group with UTC per-line stamping. After `SAMPLE_TIMEOUT_S`=600 the group is SIGKILLed, the log is kept with a "killed after" line, and the sample gets `timed_out: true`, `exit_code: null`, `all_steps_held: null`. The loop has an overall `TIMING_BUDGET_S`=1200 inside the 25-min job, because 7x600 s would not fit; a sample with no time left is recorded as timed out with `started: false`. Records go to samples.jsonl one per sample. The parse step is `if: always()` and tolerates a missing samples.jsonl. The JSON keeps every old field and adds `timed_out`, `started`, `timeout_seconds`, `uv_cache_entries_at_start` and a top-level `design` block. The final check needs 5+2 samples and fails on any timeout, non-zero exit or missing held marker.

An invalid file prints "INVALID, no figures reported" plus its problems, and the exit status stays 0. Cold and warm are separate blocks and never pooled. Each block gets a totals line and a one-line verdict. Cold p50/p95 are compared with 120/180 s ("within"/"over target"). Warm is never compared with the target. Fewer than 5 samples in a block gives raw values only and no percentile claim (§8.3). A percentile that lands on a failure is "not reached", and the output notes "p95 of n is the maximum" when n < 20 (§8.2).

Deviations:
- The timeout uses a stdlib Python runner (subprocess + process-group kill), not timeout/gtimeout. This makes it the same on both OSes and replaces the bash stamp_lines filter.
- There is also a whole-loop budget (TIMING_BUDGET_S=1200). The brief only asked for per-sample timeouts, but 7x600 s can exceed the 25-min job.
- The warm cache is the one the 5th cold sample filled. No extra untimed priming run, so there is no extra network.
- The internal artifact file samples.tsv is replaced by samples.jsonl. It is not a repo file, and the JSON field names are unchanged.
