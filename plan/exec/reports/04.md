- `src/arci/init.py` (new): `parse_request` (in-process checks in ADR order: argument syntax incl. `--task`/`--task-file` exclusion, `--n` 1..10000, `--out` suffix; experiment id `[A-Za-z0-9][A-Za-z0-9._-]*`; reference syntax via the frozen AgentRef pattern; task JSON (object only, NaN/Infinity/overflow refused); `--fault NAME[:TOOL[:OCC]]` (only `tool_timeout`, `tool_error_once`, `empty_result`; TOOL omitted or empty = any tool; OCC omitted = 0); output collision (`--force` replaces only a regular file; directory, symlink (incl. dangling) and other non-regular files are never replaced; missing parent directory refused)). `check_references`: ONE child `sys.executable -P -c <script>`, env `PYTHONPATH = child_pythonpath(())`, `start_new_session=True`, 30 s deadline (`deadline=` keyword for tests), process group SIGKILLed on timeout AND after every check (no descendant survives), stdin/stdout/stderr are temp files (no pipe can stall the parent). The child imports each module, then `contracts.resolve` (import error / missing attribute / not callable distinguished), in order baseline, candidate, toolset, oracle; calls the toolset factory once with `(task, 0)`, reads `.tools` (a Mapping of str) and checks `.snapshot` is callable. Agents, oracle, tools and snapshot are never called; the parent never imports a reference (tested via `sys.modules`). Fault TOOLs are checked against the advertised keys. `render_descriptor`: the five-line ADR header, then keys with every string value double-quoted (PyYAML dumper with a quoted-str representer; task as a one-line flow mapping). ## Deviations (with reason)
1. `runner.child_pythonpath` added beside `_pythonpath` (brief: "`_pythonpath` only"): strict basedpyright forbids importing the private name; a public alias avoids a `# pyright: ignore`.
2. The fault-tool message appends the advertised tools: `--fault tool_timeout:charge:0: tool charge absent from --toolset tests.world:make_world; choose an advertised tool (reserve)`. The other ADR messages are verbatim (`module not importable; check module and dependencies`, `output arci.yaml exists; use --force to replace it`). Messages the ADR does not list are mine: missing attribute (`module app.v2 has no attribute runn; check the function name`), not callable (`NAME is not callable; reference a function`), toolset call/tools/snapshot failures, timeout, child exited before reporting, all syntax errors (see tests for exact lines).
3. argparse-level errors (missing required flag, unknown flag) keep the CLI's existing `error: CliError: <argparse message>` form without the `init:` prefix: `_Parser.error` is outside my regions. Everything init validates itself carries `init:`.
4. Added check: `--out` must end in `.yaml`/`.yml`, because `arci run` treats any other path as manifest JSON (the printed next command would fail otherwise).
5. `NAME::OCC` (empty TOOL) is accepted as "any tool at OCC"; the ADR says only "omitted TOOL means any tool".
6. `task_id` is not written (the loader's ruling 1 makes it the experiment id); asserted after reload.
7. `tests/unit/descriptor/test_run_yaml.py` (T03, my lane): its `stderr == ""` assertion for an N=6 run now expects exactly the task-05 notice lines.
