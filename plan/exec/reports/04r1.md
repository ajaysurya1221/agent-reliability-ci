## Changes

- 1 `src/arci/cli.py` (smoke region only): `smoke_notice` uses Astra's exact text. In domain: "under this design's fixed-sample Clopper–Pearson rule two perfect arms cannot PASS below N=x and a total collapse cannot BLOCK below N=y; expect INCONCLUSIVE. The header keeps the manifest's own alpha, delta and K. "default rule" appears nowhere. The en dash is written as `–`, so ruff RUF001 does not fire. - 1b `src/arci/init.py` `publish`: without --force, `os.link` raising `FileExistsError` gives "exists; use --force". Any other `OSError` goes to `_create_exclusive`, which uses `os.open(O_WRONLY|O_CREAT|O_EXCL)`, writes the verified staged bytes, fsyncs and closes. On failure it unlinks the destination only while it is still the inode it created (st_dev/st_ino compared). If `O_EXCL` hits an existing entry, the result is also "exists; use --force". There is no `os.replace` fallback any more. The staged file is always removed.
- 1c `mkstemp` and `os.fdopen` now sit inside the `try` (the fd is closed if fdopen fails). An unwritable directory gives "output <path>: cannot write: Permission denied" and writes nothing.
- 1d `src/arci/descriptor.py` `_check_node`: a second `<<` in one mapping now raises `descriptor <src>:<path>: duplicate merge key "<<" at line L, column C; merge several mappings with <<: [*a, *b]`. `<<: [*a, *b]` and explicit overrides are still allowed.
- 1e `next_command` prints `arci run -- <path>` when the path starts with `-`.
- 1f `header(n)`: when N >= `NON_SMOKE_N` (100, tested equal to `cli.SMOKE_N_BELOW`), lines 2–3 become the ADR's "# design: N trials per arm, chosen by you; plan it with arci plan" / "# This file was written by arci init; re-run init or edit to change the design.". `HEADER` is unchanged for N < 100.

## Deviations

- The exclusive create uses mode `0o666` (the kernel applies the umask), not the brief's `0o644`. Both publication paths therefore give the same mode, `0o666 & ~umask`, which is what the hard-link path and the existing test already assert. Under the default umask 022 the result is 0644 either way.
- `--n` also gets a digit-length guard. Without it a numeric string over 4300 digits makes `int()` raise ValueError, a crash instead of the one-line error. It is tested.
- The "module not importable" wording now carries the detail, as the follow-up asked. ADR 0008's example line is shorter; the ADR presents it as an example and is frozen, so I did not edit it.
