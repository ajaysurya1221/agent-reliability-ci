# REPORT 03 — Status DONE

## Changes
- `src/arci/descriptor.py` (new): `Descriptor`, `DescriptorCondition`, `DescriptorFault` (extra="forbid", frozen); it reuses the frozen `ArmSpec`, `CommandSpec`, `McpServerSpec`, `DecisionSpec`, `ContractSpec` and `Budgets` unchanged. `Descriptor.to_manifest()` calls `Manifest.create(..., created_at="")`. Also `DescriptorError(ValueError)` (`.source`, `.path`, `.message`), `loads_descriptor`, `load_descriptor`, `compile_descriptor(path)`, `compile_descriptor_text`, `render_schema`, `DescriptorLoader`, `parse_yaml`.
  - Aliases: `oracle` -> `contract.oracle` (exactly one of the two); `id` -> `condition_id`; `fault` -> `faults`; `occurrence` -> `at_occurrence`. An alias and its full key are rejected together even when their values are equal (checked with `model_fields_set`). Defaults: bucket falsify, tool null, occurrence null, params {}. Fault names are checked against `perturb.REGISTRY` or the frozen AgentRef pattern, which is read from `AgentRef` rather than restated; nothing is imported. A non-empty `unobservable` is rejected through `contracts.validate_contract`. Decision-fault, kind and looks rules stay with the frozen Manifest validators. `schema_version`, `record_sha256`, `created_at` and `$schema` are unknown keys. `fixtures_sha256` is passed through as an opaque value.
  - Errors: one line, `descriptor <file>:<source-path>: <message>`. The source path uses the keys the file used, with zero-based indices; it is built by walking the pydantic loc against the input, which drops union tag segments. When there are several errors, the first by source path is reported. A tuple's spurious `too_short` error is dropped when an item error under it exists. Control characters are escaped. Manifest-level validator errors carry no path (`descriptor arci.yaml: tool_timeout cannot target decisions`).
- `src/arci/cli.py`, descriptor regions only:
  - one import block;
  - `_run_manifest` (.yaml/.yml is compiled and sealed; any other path is JSON as before, seal checked) and `_cmd_schema`;
  - a 1-line region inside `_cmd_run`;
  - the `run` parser: metavar PATH, `--out` default `runs`, help text;
  - the `schema` subcommand and its dispatch.
  The dest `manifest_json` is unchanged. A DescriptorError becomes a CliError, so main() prints `error: CliError: descriptor arci.yaml:n_per_arn: unknown key "n_per_arn"`, exits 3 and leaves stdout empty.
- `docs/schema/arci.schema.json` (generated, 589 lines): title "ARCI experiment descriptor", $id `.../v0.8.0/docs/schema/arci.schema.json`, plus `"$schema": draft 2020-12`. Optional-but-not-null keys (`id`, `condition_id`, `fault`, `oracle`, `contract`) are shown without the null branch.
- `docs/DESCRIPTOR.md` (197 lines): key table, arms, conditions/faults, command experiments, parsing rules (kept separate from load_contract), errors, editor comment line, Pydantic authoritative, Python builder as the advanced path, and both examples. The guardrail task is abbreviated to 2 of 182 commands to stay under 200 lines.
- `tests/unit/descriptor/{__init__,test_descriptor,test_schema_file,test_run_yaml}.py`.

## Deviations
- The ruling's text was followed literally for booleans: `True`/`TRUE` stay strings, unlike the YAML 1.2 core schema. This is documented and tested.
- The YAML 1.1 `=` (value) resolver was also dropped: under plain SafeLoader a bare `=` crashes with a constructor error; now it is a string.
- The error line uses the dispatch's `error: CliError: descriptor ...` form, not Astra's `arci: descriptor ...`.
- `arci schema --out` prints nothing on stdout.

## Open issues
- Duplicate YAML keys are silently last-wins (PyYAML behaviour), e.g. two `n_per_arm:` lines. Rejecting them needs a constructor override in `DescriptorLoader`. Not done: outside the ruling.
- Manifest-level validator errors (experiment kind, decision faults, looks) are reported at the file root without a source path.
- A non-string YAML key such as `true:` prints as `[1]` in the path. This is cosmetic.
- The guardrail example in DESCRIPTOR.md is abbreviated. The full 182-command file is generated in the test from `public_task("ask")`.
