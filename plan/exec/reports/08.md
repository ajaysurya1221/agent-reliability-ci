## Deviations
- The test runs `arci run arci.yaml` exactly as the README writes it (the memo's command), not `... --workers 4`: `--workers` defaults to 4 (`src/arci/cli.py`, `run` parser), so it is the same run, and (c) requires the README's commands to be the ones the test runs.
- The README adds a setup line (`cp -R examples/recipes/python_agent checkout && cd checkout && rm arci.yaml`): the committed `arci.yaml` is exactly what `arci init` writes, and init refuses an existing file without `--force`, so running the memo command in an unmodified tree would exit 3. The test emulates those three commands (copytree, cwd, unlink) and asserts they are the README's first three.
- Test (c) is stronger than asked: it pins the full ordered list of README bash commands, runs every `arci` command except `arci run confirm.yaml` (800 trials, about 90 s; the confirm descriptor is still written by the README's command, extended with the README's yaml block, and compiled/seal-checked), and skips `uv tool install` (network).
- The confirmatory run uses a new experiment id with `base_seed: 1000` and `prior_runs` added by hand (README yaml block), so its seeds are disjoint from the smoke run's and the report lists the smoke run; init has no flags for either.
