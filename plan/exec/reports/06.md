## Deviations

- Guard and build are one job (`build`, step "Refuse to build unless the tag is v plus the package version"),
  as the dispatch specified ("guard+build"), not a separate `guard` job.
- The guard also refuses non-tag refs, so a `workflow_dispatch` from a branch stops at build (a dispatch
  started on a tag ref works). Reason: no path to PyPI without a matching tag.
- publish verifies `SHA256SUMS` before removing it (addition; catches an artifact altered between jobs).
- `chmod +x` on the script was denied by the sandbox; it is committed 0644 and always invoked as
  `bash .github/scripts/wheel_smoke.sh`. The orchestrator may set the bit (`git update-index --chmod=+x`).
