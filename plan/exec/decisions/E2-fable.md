## 1. Key reference (names are the Manifest's wherever a Manifest field exists)

| key | type | default | → Manifest |
|---|---|---|---|
| `experiment_id` | str, required | | `experiment_id` |
| `task_id` | str | `experiment_id` | `task_id` |
| `task` | mapping | `{}` | `task` |
| `toolset` | ref | | `toolset` (python experiments) |
| `mcp_server` | mapping `{name, argv, env, snapshot}` | | `mcp_server` (command experiments) |
| `decisions` | mapping (DecisionSpec fields) | | `decisions` |
| `oracle` | ref, required | | `contract.oracle` (alias) |
| `contract` | mapping of the other ContractSpec fields | `{}` | merged with `oracle` into `contract` |
| `baseline`, `candidate` | ref string or arm mapping, required | | `baseline`, `candidate` |
| `conditions` | list, ≥1, required | | `conditions` |
| `alpha`, `delta`, `n_per_arm`, `base_seed`, `interval_method`, `looks`, `prior_runs`, `budgets` | as Manifest | Manifest defaults | same names |

Aliases: `oracle` (top level), `id` → `condition_id`, `occurrence` → `at_occurrence`, `fault` (one
mapping) → `faults` (one-element list). Nothing else is renamed. Unknown keys anywhere → error.

## 2. Arms

- Bare string `app.v1:run` → `ArmSpec(label=<derived>, agent="app.v1:run", candidate_id="app.v1:run")`.
  Label = `<last module segment>.<function>` (`v1.run`), so two arms whose functions share a name
  stay distinguishable in reports.
- Mapping `{label, agent | command: {argv, env, infra_exit_codes}, candidate_id}` → `ArmSpec` as is.

## 3. Conditions and faults

```yaml
conditions:
  - id: reserve-timeout
    faults:
      - {name: tool_timeout, tool: reserve, occurrence: 0, bucket: falsify, params: {}}
```
`bucket` default `falsify`; `tool` omitted = any tool; `occurrence` omitted = the perturbation's
default; `params` default `{}`. Fault `name` must be in `perturb.REGISTRY` or `module:function`
(checked at load). Decision faults (`decision_low_confidence`, `decision_unavailable`) are written
the same way with `tool: decision:systemone`; the frozen Manifest validators do the rest.

## 4. Command agents (guardrail translated)

```yaml
experiment_id: guardrail-live-b-ask-provider_down-50
task_id: ...
task: {...}
mcp_server:
  name: env
  argv: [python, -P, -m, arci.mcp_toolset_server, --toolset, examples.guardrail_agent.world:make_world,
         --workdir, "{workdir}", --seed, "{seed}", --task-file, "{task_file}"]
  snapshot: arci.mcp_toolset_server:snapshot
decisions: {upstream: fixture, fixture: examples.guardrail_agent.decisions:fixture, model: jev-1.13.0}
oracle: examples.guardrail_agent.world:oracle
baseline: {label: A, command: {argv: [python, -P, -m, examples.guardrail_agent.agent, --mcp-config, "{mcp_config}", --task-file, "{task_file}"]}}
candidate: {label: B, command: {argv: [...]}}
conditions:
  - id: provider_down
    faults: [{name: decision_unavailable, tool: "decision:systemone", occurrence: 0}]
n_per_arm: 50
```
Placeholders stay literal strings. `sys.executable` is not available in YAML: the argv uses
`python` (resolved on PATH) or an absolute path; the docs say which.

## 5. Not exposed

`schema_version` (loader sets `arci/0.5`), `record_sha256` and `created_at` (the seal is computed
by `Manifest.create`; `created_at` is set by the loader at seal time), `fixtures_sha256` (left `""`,
as the builders do). A file carrying any of them is rejected as an unknown key.

## 6. JSON Schema

Title `ARCI experiment descriptor`, `$id`
`https://raw.githubusercontent.com/ajaysurya1221/agent-reliability-ci/main/docs/schema/arci.schema.json`,
generated by `Descriptor.model_json_schema()`, printed by `arci schema`, committed at
`docs/schema/arci.schema.json`, staleness-tested. Editors: the first line
`# yaml-language-server: $schema=<that URL>` (a comment, so the loader never sees a `$schema` key).
Docs state: Pydantic is authoritative; the schema is a convenience and cannot express the
cross-field validators (exactly one of agent/command, python-vs-command kind, decisions rules).

## 7. YAML 1.1

The loader uses a `SafeLoader` subclass whose bool resolver accepts only `true|false` and whose int
resolver accepts only decimal, `0x`, `0o`, `0b` (no leading-zero octal, no sexagesimal); timestamps
stay strings. `arci init` quotes every string it writes. Docs carry one sentence on it.

## 8. Errors (one line, stderr, exit 3)

`error: arci.yaml: conditions[0].faults[0]: unknown key 'occurence' (did you mean 'occurrence'?)`,
`error: arci.yaml: baseline: 'app.v1:run' is not module:function`,
`error: arci.yaml: conditions[0].faults[0].name: unknown fault 'foo' (built in: ...; or module:function)`.

## 9. Example: the retry demo

```yaml
# yaml-language-server: $schema=https://raw.githubusercontent.com/ajaysurya1221/agent-reliability-ci/main/docs/schema/arci.schema.json
experiment_id: arci-demo-agent_b-reserve-timeout-200
task_id: confirm-inventory-order
task: {order_id: "order-7", sku: "widget", quantity: 2, stock: 10}
toolset: arci.demo.world:make_world
oracle: arci.demo.world:oracle
baseline: {label: agent_a, agent: arci.demo.agents:agent_a, candidate_id: baseline-a}
candidate: {label: agent_b, agent: arci.demo.agents:agent_b, candidate_id: candidate-agent_b}
conditions:
  - id: reserve-timeout
    faults: [{name: tool_timeout, tool: reserve, occurrence: 0}]
n_per_arm: 200
base_seed: 12000
budgets: {max_tool_calls: 10, max_model_steps: 10, max_seconds: 15.0}
```
This must seal byte-identically to `arci.demo.experiment.build_manifest(200, "agent_b")`.
