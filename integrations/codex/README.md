# realornoise as a Codex skill

Copy the folder `skills/realornoise` into `~/.agents/skills/` (Codex reads user skills from
there), then ask Codex to run the `realornoise` skill. The skill only runs `uvx realornoise`
and shows what it prints. What it prints (counts, rates, dates and the names of the model and effort compared)
then becomes part of the conversation.
